1
Entendendo o problema — decomponha em componentes +

Antes de codificar, analise o term.ooo como um engenheiro React. Quebre a tela em componentes reutilizáveis:

  • Grid — 6 linhas × 5 letras (o tabuleiro completo)
  • Row — uma tentativa de 5 letras
  • Tile — cada quadradinho individual com cor de feedback
  • Keyboard — teclado virtual com estado de cores
  • Modal — resultado final (vitória ou derrota)

Regra React: se algo aparece mais de uma vez, é um componente. O Tile aparece 30 vezes — definitivamente um componente.

3
Estado central com useState no custom hook +

Todo o estado do jogo fica em useGame.js. O princípio é o mesmo do tutorial Tic-Tac-Toe: estado sobe para o ancestral comum.

import { useState, useCallback } from 'react'
import { getRandomWord, isValidWord } from '../utils/wordList'

export function useGame() {
  const [answer]  = useState(getRandomWord())
  const [guesses, setGuesses] = useState([]) // array de strings
  const [current, setCurrent] = useState('')  // tentativa atual
  const [error,   setError]   = useState(null)
  const [gameOver,setGameOver]= useState(false)

  const submitGuess = useCallback(() => {
    if (current.length !== 5) {
      setError('Palavra precisa ter 5 letras'); return
    }
    if (!isValidWord(current)) {
      setError('Palavra não encontrada'); return
    }
    const next = [...guesses, current]
    setGuesses(next)
    setCurrent('')
    setError(null)
    if (current === answer || next.length === 6)
      setGameOver(true)
  }, [current, answer, guesses])

  return { guesses, current, setCurrent,
            submitGuess, answer, gameOver, error }
}

Por que custom hook? Separa lógica de apresentação. O App.jsx fica limpo — só compõe componentes.

Captura de teclado físico com useEffect +

Use useEffect para adicionar e remover o event listener corretamente:

useEffect(() => {
  const handler = (e) => {
    if (gameOver) return

    if (e.key === 'Enter')     { submitGuess(); return }
    if (e.key === 'Backspace') {
      setCurrent(c => c.slice(0, -1)); return
    }
    // aceita letras PT-BR
    if (/^[a-záéíóúãõç]$/i.test(e.key) && current.length < 5) {
      setCurrent(c => c + e.key.toUpperCase())
    }
  }

  window.addEventListener('keydown', handler)
  return () => window.removeEventListener('keydown', handler)
  // dependências: sempre inclua o que o handler usa
}, [current, gameOver, submitGuess])

Erro clássico: esquecer current ou submitGuess no array de dependências causa bugs de closure — o handler "vê" o valor antigo.

6
Conectando tudo no App.jsx +

O App.jsx é só composição — nenhuma lógica, só props:

export default function App() {
  const {
    guesses, current, answer,
    setCurrent, submitGuess, gameOver, error
  } = useGame()

  return (
    <main className="app">
      <h1>TERMO</h1>

      {error && <p className="error">{error}</p>}

      <Grid
        guesses={guesses}
        current={current}
        answer={answer}
      />

      <Keyboard
        onKey={(k) => setCurrent(c => c + k)}
        onEnter={submitGuess}
        onDelete={() => setCurrent(c => c.slice(0,-1))}
        guesses={guesses}
        answer={answer}
      />

      {gameOver && (
        <Modal
          won={guesses.at(-1) === answer}
          answer={answer}
          attempts={guesses.length}
        />
      )}
    </main>
  )
}

1
Entendendo o problema — jogo sem limite de tentativas +

O Contexto usa similaridade semântica (word embeddings). O jogador digita qualquer palavra e recebe um número de distância — quanto menor, mais próxima da resposta.

  • Sem limite de tentativas — o jogador pode tentar infinitamente
  • Lista ordenada por proximidade — as melhores tentativas ficam no topo
  • Feedback visual — cor "quente/frio" baseada no ranking

Backend: use a API pública api.contexto.me ou simule com um JSON pré-computado de similaridades.

2
Chamada de API com async/await +

A lógica central é buscar a distância semântica ao submeter:

const [guesses,  setGuesses]  = useState([])
const [input,    setInput]    = useState('')
const [loading,  setLoading]  = useState(false)
const [won,      setWon]      = useState(false)

async function handleGuess() {
  if (!input.trim()) return
  setLoading(true)
  try {
    const res  = await fetch(
      `https://api.contexto.me/machado/pt/tip/${gameId}/${input}`
    )
    const data = await res.json()
    // data = { word, distance, lemma }

    setGuesses(g =>
      [...g, data].sort((a, b) => a.distance - b.distance)
    )
    if (data.distance === 1) setWon(true)
    setInput('')
  } catch (err) {
    console.error(err)
  } finally {
    setLoading(false)
  }
}

function getHeat(distance) {
  if (distance <=  100) return { color: '#e63946', label: '🔥 Fervendo' }
  if (distance <=  500) return { color: '#f4a261', label: 'Quente'     }
  if (distance <= 2000) return { color: '#457b9d', label: 'Morno'      }
  return                 { color: '#adb5bd', label: '❄️ Frio'    }
}

function GuessItem({ word, distance }) {
  const { color, label } = getHeat(distance)
  return (

      <span style={{ color, fontWeight: 'bold' }}>#{distance}</span>
      <strong> {word}</strong>
      <small style={{ color, marginLeft: '8px' }}>{label}</small>
    </div>

}
4
Persistência com localStorage +

Salve o progresso para o jogador poder voltar depois do mesmo ponto:

// carregar ao montar
useEffect(() => {
  const saved = localStorage.getItem(`contexto-${gameId}`)
  if (saved) setGuesses(JSON.parse(saved))
}, [gameId])

// salvar ao mudar
useEffect(() => {
  localStorage.setItem(
    `contexto-${gameId}`,
    JSON.stringify(guesses)
  )
}, [guesses, gameId])

Padrão React: dois useEffect separados — um para carregar, um para salvar. Mais legível que um único efeito com condição.

1
Entendendo o problema — estado complexo +

O Conexo/Connections tem 16 palavras que formam 4 grupos secretos. O jogador seleciona 4 por vez e submete a hipótese.

  • 4 grupos com dificuldade crescente (🟨🟩🟦🟪)
  • 4 erros permitidos — após isso, game over
  • Animações — shake ao errar, flip ao acertar
  • Estado interdependente — ideal para useReducer

Regra React: quando múltiplos estados mudam juntos em resposta a uma ação, use useReducer ao invés de vários useState.

2
useReducer — centralizando toda a lógica +

O reducer define todas as transições de estado possíveis do jogo:

const initialState = {
  words:    shuffle(allWords),  // 16 palavras embaralhadas
  selected: [],                  // máximo 4 selecionadas
  solved:   [],                  // IDs dos grupos resolvidos
  mistakes: 0,                  // contador de erros
  status:   'playing',          // 'playing' | 'won' | 'lost'
  shaking:  false               // animação de erro
}

function reducer(state, action) {
  switch (action.type) {
    case 'TOGGLE':
      return handleToggle(state, action.word)
    case 'SUBMIT':
      return handleSubmit(state)
    case 'SHUFFLE':
      return {...state, words: shuffle([...state.words])}
    case 'STOP_SHAKE':
      return {...state, shaking: false}
    default:
      return state
  }
}

const [state, dispatch] = useReducer(reducer, initialState)
// uso: dispatch({ type: 'TOGGLE', word: 'BANANA' })

Grid selecionável com feedback visual +

O grid usa CSS Grid 4×4 com highlight ao selecionar:

function WordGrid({ words, selected, onToggle, shaking }) {
  return (
    <div style={{
      display: 'grid',
      gridTemplateColumns: 'repeat(4, 1fr)',
      gap: '8px'
    }}>
      {words.map(word => {
        const isSelected = selected.includes(word.text)
        return (
          <button
            key={word.text}
            onClick={() => onToggle(word.text)}
            className={`word-btn ${isSelected ? 'selected' : ''}
                        ${shaking && isSelected ? 'shake' : ''}`}
          >
            {word.text}
          </button>
        )
      })}
    </div>
  )
}

4
Lógica de submissão no reducer +

A função handleSubmit dentro do reducer verifica o grupo e atualiza tudo atomicamente:

function handleSubmit(state) {
  const ids = state.selected.map(w => w.groupId)
  const allSame = ids.every(id => id === ids[0])

  if (allSame) {
    // acertou o grupo!
    const solved = [...state.solved, ids[0]]
    return {
      ...state,
      selected: [],
      solved,
      words: state.words.filter(w => w.groupId !== ids[0]),
      status: solved.length === 4 ? 'won' : 'playing'
    }
  }

  // errou
  const mistakes = state.mistakes + 1
  return {
    ...state,
    selected: [],
    mistakes,
    shaking: true,
    status: mistakes >= 4 ? 'lost' : 'playing'
  }
}

Boa prática: após o dispatch de erro, use setTimeout(() => dispatch({type:'STOP_SHAKE'}), 600) no componente para parar a animação.
